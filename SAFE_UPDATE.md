# Безопасное обновление Fable 5

Версия 1.3.1 содержит отдельную программу обновления. Нужны Node.js 20+,
Git и совместимый Codex CLI в PATH. npm при запуске не требуется.
Плагин должен быть установлен и включён. Проверено на Codex
0.165.0-alpha.1.2 под Windows; совместимость с будущими CLI требует проверки.
Обычные команды установки Codex не запускают этот механизм автоматически.

## Запуск

Узнайте установленную версию:

```sh
codex plugin list --marketplace fable5 --json
```

Пакет находится в пользовательском каталоге Codex:
`~/.codex/plugins/cache/fable5/fable5-codex/<version>`.
При нестандартном профиле используйте его фактический каталог.
Передайте существующий абсолютный путь проекта:

```sh
node /absolute/path/to/plugin/mcp/dist/update.mjs update --project /absolute/path/to/project
```

По умолчанию проверяется `main`. Для конкретного релиза добавьте `--ref <tag-or-commit>`.
При переходе с 1.2.0 сначала скачайте доверенную версию репозитория 1.3.1,
затем запустите эту же команду с `mcp/dist/update.mjs` из checkout. Она сохранит
уже установленную 1.2.0 до её замены. Обновляющая программа выполняет код
кандидата при проверке MCP; выбирайте доверенный репозиторий и ref.

## Что сохраняется и проверяется

До изменения установки создаётся каталог
`~/.codex/plugin-backups/fable5-codex/<timestamp-id>/`:

- `config.toml` — полная приватная копия настроек;
- `package/` — весь прежний пакет с SHA-256 каждого файла;
- `snapshot.json` — настройки Fable, источник, версия и контрольные суммы;
- `recover.mjs` — автономная программа восстановления;
- `transaction.json` — фазы операции и её результат.

Содержимое конфигурации не печатается и не отправляется в GitHub. Каталог
создаётся в профиле пользователя; POSIX-права ограничиваются владельцем,
в Windows наследуется ACL профиля. Храните его приватно: config.toml может
содержать секреты. Хеши обнаруживают повреждение файлов, но не являются
подписью против атакующего, способного переписать весь бэкап.

Кандидат сначала скачивается отдельно и проверяется по manifest/build-info.
Свободное место проверяется до бэкапа и повторно перед установкой; нужен
запас минимум 128 МиБ перед началом, для большого пакета — больше.
Установка использует родные команды Codex и точный Git SHA. Затем проверяются
все файлы пакета, загрузка скилла родным каталогом Codex и реальные MCP
`tools/list`, `search_skills`, `read_skill`. Запуск MCP ограничен по времени.
Настройки одобрения MCP и прочие настройки целевого плагина сохраняются.

После успеха marketplace закреплён на проверенном SHA. Следующий safe update
снова разрешает `main` или указанную ref. Существующему окну Codex может
потребоваться перезапуск или новый чат для обновления каталога инструментов.

## Откат и результаты

В Windows работающий MCP может удерживать каталог старой версии. Если Codex
не может заменить этот cache entry, updater устанавливает прежний код в новый
каталог с версией `<old-version>+recovery.<id>`. Меняется только поле version
в plugin.json; все остальные байты проверяются по бэкапу. Процессы Codex/MCP
не завершаются. Источник остаётся локальным recovery-каталогом внутри бэкапа,
который нельзя удалять до следующего успешного обновления. Результат содержит
`version` исходного пакета и отдельную фактическую `installed_version`.

При завершившейся ошибкой установке или проверке автоматически ставится
прежний SHA. Если Git недоступен, используется `package/` из бэкапа; источник
остаётся локальным, поэтому не удаляйте этот бэкап. Следующий safe update
сможет вернуть источник GitHub. Старая версия повторно проходит health check.

Полный config.toml автоматически не подменяется: через API Codex
восстанавливаются только таблицы `plugins."fable5-codex@fable5"` и
`marketplaces.fable5`. Остальные настройки, включая изменившиеся за время
обновления, сохраняются. При Git-откате ref фиксируется на прежнем SHA.

JSON-результат и код завершения:

| Статус | Код | Значение |
| --- | --- | --- |
| `updated` | 0 | Новая версия установлена и проверена |
| `rolled_back` | 2 | Прежняя версия восстановлена и проверена |
| `unchanged` | 3 | Ошибка подготовки; установка не менялась |
| `recovery_required` / `failed` | 3 | Успех не подтверждён; изучите журнал/код ошибки |

`--help` возвращает 0 без подключения к Codex. Бэкапы не очищаются
автоматически. Одновременные safe updates блокируются `active.json`.
При неизвестном результате записи, конфликте настроек или ошибке отката
журнал и блокировка сохраняются. После устранения причины выполните явное
восстановление из пути `backup`, выведенного программой:

```sh
node /absolute/path/to/backup/recover.mjs rollback --project /absolute/path/to/project --backup /absolute/path/to/backup
```

Программа проверит целостность копии перед восстановлением. Повторный rollback
допустим. Живой процесс обновления нельзя перебить этой командой; блокировка
завершившегося процесса той же транзакции снимается автоматически. Повреждённый
бэкап или чужая блокировка требуют разбора, а не принудительного перезаписывания.

## Границы и проверка отката

Updater предназначен для этого плагина и полного marketplace, отказывается
от обновления локально изменённого пакета, выключенного плагина или
несогласованных cache/marketplace. Не меняет бинарники Codex, проекты,
auth.json или чужие плагины. Это восстановление после ошибок установки,
а не гарантия при отказе диска, потере питания или несовместимости старой
версии с изменившимся Codex. Если отсутствует Node/Codex, восстановление
потребует вернуть соответствующую среду запуска.

Детерминированные проверки: `cd mcp && npm test` после `npm run build`.
Настоящая репетиция: `node mcp/test/native-update.mjs /absolute/path/to/project`.
Она создаёт временный
marketplace с уникальным именем в текущем профиле Codex, использует настоящий
CLI и MCP и удаляет только тестовую регистрацию. Рабочий Fable не переключает.
Проверяются сломанный кандидат → Git-откат, недоступный источник → локальный
откат, успешное обновление → два ручных отката и сохранность остальных настроек.
При провале временные приватные артефакты остаются для разбора. Это отдельная
локальная интеграция, не имитация CI и не доказательство для всех версий Codex.
