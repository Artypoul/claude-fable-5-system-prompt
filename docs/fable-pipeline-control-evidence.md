# Проверка цепочки Fable 5 и Gigma Superpowers

**Итог:** код и спецификация прошли независимое ревью; исправления отчёта и свидетельств повторно проверены тем же ревьюером. Автоматический запуск всей цепочки для любой команды подтверждён лишь частично.

## Результат контрольной задачи

В существующем репозитории создан отдельный образец: чистая функция `normalize_paths` и JSON-команда для приведения относительных путей к единому виду. Функция не обращается к файлам или сети. Она проверяет абсолютные пути, выход выше корня, буквенные префиксы дисков, типы и некорректные строки, сохраняет значимые пробелы и регистр и удаляет повторы с сохранением порядка. Команда выдаёт JSON на успешном вводе либо одну строку ошибки без исходных данных при неверном вводе.

Основной агент отдельно проверил CLI: вход `['assets\\icons\\..\\logo.svg', './docs/readme.md', 'docs/readme.md']` дал `['assets/logo.svg', 'docs/readme.md']`, код 0 и пустой stderr; `['../outside']` дал код 2, пустой stdout и `Invalid input` на stderr.

После исправления кодировки основной агент отдельно проверил байтовый ввод: UTF-8 `café` при окружении CP1252 дал код 0 и корректное JSON-значение; некорректные последовательности `FF` и `ED B3 BF` дали код 2, пустой stdout и одну строку `Invalid input`. Это проверка конкретных примеров, а не доказательство всех возможных входов.

## Границы наблюдения и артефакты

Контролируемый основной сеанс прочитал установленный Fable, применил bootstrap/router и выполнил SDD по согласованному плану. В его дочерних контекстах исполнители и ревьюер Task 1 сообщили, что Fable MCP не был им доступен, и использовали разрешённый каталог хоста. Это не успешный вызов MCP у этих агентов. Отдельная прямая stdio-проверка и отрицательные случаи также записаны в `observables.jsonl`; их нельзя выдавать за автоматическое использование MCP естественной командой. Артём попросил выполнить реальную задачу по триггеру Fable; основной агент выбрал отдельный native-сеанс и прервал исходного исполнителя Task 2 для передачи. Это отклонение от предусмотренного планом возврата исправления тому же исполнителю; Артём не задавал эти механические шаги.

Рабочие свидетельства находятся в `.superpowers/sdd/2026-11-07-fable-pipeline-control/`: `observables.jsonl`, `model-receipts.json`, `commands.log`, `progress.md`, `task-1-brief.md`, `task-1-report.md`, `task-1-review.md`, `task-2-brief.md`, `task-2-report.md`, `task-2-review.md`, `utf8-fix-report.md`, а также пакеты Git diff. `review-12cb46b..f2f5b24.diff` — исторический, до исправления; актуальный пакет указан отдельно. Текущие SHA-256: модуль `71e0126bcb55dcf3b82dc8adab8fb5b218f617765d284bdcb44d0864cce058e0`, тест функции `96eccdba8b7a0673b5940f14a3f1776d0319ac9154e6d9b2ff15e84046d0f5a7`, тест CLI `1cbbf306107d6cf2142a11f7f877299a09a9640e413eaf1831eb4a7fb57270e8`.

Штатный Bash-помощник SDD в Windows не запустился: `bash` оказался WSL launcher без дистрибутива. По согласованному решению корневого агента папка, marker и briefs созданы средствами PowerShell/Python с проверкой содержимого, а review-пакеты — штатным Git diff; выполнение самих Bash-скриптов не утверждается.

Работа ограничена локальной веткой `codex/fable-pipeline-control` и шестью согласованными файлами, включая этот отчёт. Публикации, push, установки или намеренных изменений скиллов и глобальных настроек в этой контрольной задаче не выполнялось. При последней сверке 86 отслеживаемых файлов исходного BASE, 112 файлов установленного Fable 1.3.5 и 264 файла установленного Superpowers совпали с их исходными снимками. Локальное и установленное деревья Fable SKILL/references содержат по 19 файлов с одинаковыми хешами; однако фактически в описанном native CLI сеансе читался локальный путь.

Автор и причина изменения не установлены. Из совпадения остальных хешей нельзя заключать, что конфигурация не менялась.

Основной агент отдельно проверил текущие ключи маршрутизации без раскрытия секретов: Fable MCP указывает на установленный `fable5-codex/1.3.5/mcp/dist/server.mjs` с bundled Node; Fable и Gigma Superpowers включены, curated Superpowers выключен.
