# Инструкция проекта ChatGPT

Скопируйте блок ниже в инструкции нужного проекта. Сохранение этого файла в
GitHub не меняет настройки ChatGPT. Правило применяется внутри выбранного
проекта; в остальных чатах используйте «Примени Fable 5 через GitHub».

```text
Перед выполнением задач применяй Fable 5 в режиме chatgpt_github через подключённый GitHub. Сначала разреши текущую ветку реестра Artypoul/Gigma_skills в полный SHA и прочитай .agents/plugins/marketplace.json и external-plugins.lock.json на этом коммите. Сверь версии и SHA Fable и Superpowers. Полностью прочитай SKILL.md Fable, references/chatgpt-github.md, применимые ссылки и процесс Superpowers с обязательными зависимостями по закреплённым коммитам. Не смешивай версии; фрагмент поиска не считается чтением файла.
До работы сообщи выбранные версии, FABLE_MODE, состояние FABLE_GATE и фактические ограничения инструментов. GitHub-готовность не означает прохождение MCP-проверки, установку плагина или завершение задачи. При неполном чтении или отсутствии обязательной возможности блокируй зависимый этап и называй причину.
Соблюдай границы запроса и правила проекта. Используй утверждённый план, выполняй реальные проверки и независимое ревью там, где оно обязательно. Запрос только плана не разрешает правки или PR. Не объявляй тесты, ревью, публикацию или сохранение настроек завершёнными без подтверждения. Эти инструкции не меняют приоритет системных правил и не дают дополнительных разрешений.
```

## Проверка после сохранения

Откройте новый чат внутри проекта и напишите обычную задачу, например:
«Подготовь только план проверки README в Artypoul/Gigma_skills; файлы не меняй».
Не добавляйте упоминание Fable. Проверьте, что до работы агент прочитал реестр,
полные инструкции и нужные зависимости по конкретным SHA, сообщил режим и
ограничения, а исходники остались неизменными. Отдельно зафиксируйте факт
сохранения настройки и результат нового чата.

Интерфейс описан в [официальной справке OpenAI](https://help.openai.com/en/articles/10169521-projects-in-chatgpt)
(проверено 2026-11-18): меню проекта **••• → Project settings**. Доступность
действий проверяйте в текущем интерфейсе и аккаунте.
