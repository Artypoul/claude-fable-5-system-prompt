# Проверка MCP-поиска перед публикацией 1.2.0

План одобрен пользователем; внешнего ревью разрешено не ждать. Ниже — три
ручных прохода автора по текущей реализации, без заявлений об отдельных агентах.

- **API и совместимость.** Источник — реальный Codex `skills/list` с явным cwd.
  `native catalogue contract` и обезличенная фикстура проверяют форму ответа,
  отключение и совпадающие имена. Пустая выдача не подменяет ошибку; неполный
  каталог помечается. Unicode, стабильный порядок и порции покрыты search tests.
- **Границы чтения и жизненный цикл.** ID разрешается через свежий каталог,
  аргумента path нет. SDK проверяет типы и границы. Проверены неизвестный ID,
  отсутствие файла, UTF-8, бинарные данные и размер; файловые symlink отвергаются.
  Windows без Developer Mode не даёт создать symlink для проверки: этот случай
  отдельно упражняет Linux CI. Native transport tests покрывают timeout,
  отмену и ограничение вывода; SDK session-close test доказывает завершение
  дочернего процесса при разрыве MCP-сессии. Shell не используется.
- **Упаковка и наблюдаемое поведение.** Самодостаточный bundle запускается
  вне репозитория без node_modules. Проверены source/bundle tampering и
  launch-конфигурация. Лицензии SDK/core/Zod сохранены. Настоящий SDK-клиент
  нашёл установленный Fable 5 и прочитал файл; отдельный ephemeral Codex exec
  действительно вызвал search_skills → read_skill, что проверено по трассе
  mcp_tool_call и содержимому результатов. Это не имитация вызовов в плане.

Локально: 54 Python-теста, 13 MCP-тестов; свежая модельная оценка — 21 сценарий,
4 проверки текста и 8 контрольных примеров. Повторное выполнение и установку
из GitHub проверяем на опубликованном commit; CI повторяет протокол и сборку.

Ограничения остаются явными: Node 20+ и Codex CLI в PATH, experimental API
каталога Codex, лексический поиск по метаданным, чтение только SKILL.md до 1 MiB.
MCP-ответ не является нативной активацией скилла и не даёт новых разрешений.
Исходный архив и source mapping не менялись; локальных блокеров не осталось.
