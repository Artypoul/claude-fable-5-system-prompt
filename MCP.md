# Поиск и чтение скиллов через MCP

Версия плагина 1.2.0 добавляет локальный stdio-сервер `fable5_skills`.
Нужны Node.js 20+ и совместимый Codex CLI в PATH. Проверенная версия Codex:
`0.165.0-alpha.1.2`; внутренний API каталога experimental и может измениться.
Собранный SDK включён в `mcp/dist/server.mjs`: установка npm-зависимостей нужна
только разработчику. При запуске сервер ничего не скачивает и не открывает порт.

## Инструменты

`search_skills` принимает `query`, абсолютный `cwd` проекта, `limit` (1–50,
по умолчанию 10) и `offset` (по умолчанию 0). Пустой запрос перечисляет каталог;
остальные запросы ищут по имени и описанию, с нормализацией Unicode и регистра.
Это лексический поиск без embeddings и отдельного вызова модели. Результат
содержит `skills`, `total`, `next_offset`, `catalog_sha256`, `partial` и
`warning_count`. При изменении отпечатка между страницами начните просмотр снова.

`read_skill` принимает `cwd`, `skill_id` из поиска, `offset` и `limit` текста
(по умолчанию 16000, максимум 32000 символов Unicode). Возвращает `content`,
`total_chars`, `next_offset` и SHA-256 полного файла. Максимальный SKILL.md —
1 MiB. Произвольного `path` в аргументах нет; текущий каталог повторно проверяется.
Отключённые скиллы не выдаются. Ссылки на файл SKILL.md отвергаются; symlink на
сам каталог скилла допускается. Текст не исполняется и не активирует скилл
нативным механизмом Codex; модель получает его как результат инструмента.

Источник — `skills/list` настоящего `codex app-server --stdio` для переданного
проекта с `forceReload: true`. Все версии кэша подряд не сканируются. Дочерний
процесс ограничен 15 секундами и 8 MiB вывода, не вызывает модель и завершается
после запроса. `FABLE5_CODEX_BIN` позволяет владельцу указать путь к Codex CLI.
Указание shell-команды вместо исполняемого файла не поддерживается.

Сбой источника возвращается с `isError: true` и кодом ошибки; это отличается от
успешного поиска с `total: 0`. Ошибки отдельных скиллов обозначаются `partial` и
счётчиком предупреждений. Сырые сообщения конфигурации/секреты не возвращаются.

## Проверка

После обычного обновления плагина начните новый чат или перезагрузите клиент,
если каталог инструментов текущего чата не обновился. Агент должен обнаружить
реальные `search_skills` и `read_skill` в пространстве имён плагина.

Для прямой проверки настоящим SDK-клиентом, без вызова модели:

```sh
cd mcp
npm ci --ignore-scripts
npm run build
npm test
npm run smoke -- /absolute/project/path
```

Smoke вызывает собранный сервер, ищет Fable 5 в настоящем каталоге и читает
найденный файл. Он требует установленный Codex; тесты CI используют обезличенный
контракт источника и не выдают фикстуру за пользовательский каталог.

Конфигурация `.mcp.json` использует `command: node`, относительные аргументы и
`cwd: ./`; Codex разрешает cwd относительно установленного корня плагина.
Поэтому перемещение кэша не требует правки абсолютных путей. Если Node не в
PATH клиента, настройте окружение запуска клиента до включения этого сервера.

SDK и его лицензии включены в bundle; `mcp/dist/THIRD_PARTY_LICENSES.txt`
содержит условия сторонних компонентов. CI пересобирает артефакт и сверяет его
с репозиторием. Упаковщик проверяет отпечатки исходников и сборки.
